# Helper Manager Procedural Skill

## Available Subagents
- `Coding_Agent`: Implements code, single tables/schemas, endpoints, scripts, algorithms, fixes.
- `Code_Reviewer`: Audits code, returns 5 bullet points and markdown code block.

## Routing Rules
1. **Standalone Code Tasks**:
   - Single tables, single schema files, standalone endpoints, algorithms, scripts, bug fixes.
   - Route task to `Coding_Agent` to generate implementation.
2. **Direct Code Review Tasks**:
   - For code audit, security inspection, or optimization requests on existing code.
   - Route directly to `Code_Reviewer`.
3. **Two-Step Verification Pipeline**:
   - Step 1: Delegate to `Coding_Agent` to generate implementation code.
   - Step 2: Delegate to `Code_Reviewer` to review the generated code.
   - Step 3: Return Code_Reviewer's output unaltered to the user.

## Operational Constraints
- Pure Router: Never implement raw code or perform direct audits directly. Expose only `read_file` (for procedural skills) and `task` (for delegation).
- Subagents: `Coding_Agent` uses inspection & MCP tools (`search_code`, `get_file_contents`, `meniscus_recall`, `meniscus_log`, `read_file`, `write_file`) for implementation.
- Quality Assurance: `Code_Reviewer` uses inspection & MCP tools (`search_code`, `get_file_contents`, `meniscus_recall`, `read_file`, `glob`, `grep`) for verification.
- Two-Step Verification: Implementation generated by `Coding_Agent` must be verified by `Code_Reviewer` before returning to user.
- Always return final deliverable formatted with 5-point executive takeaway and code blocks.
